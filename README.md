# PolyArt Live

Живые полиномиальные иллюстрации — интерактивные HTML5-визуализации, основанные на математике полиномов.

Каждая иллюстрация генерируется в реальном времени из коэффициентов полиномов. Нет зависимостей — открой HTML и всё работает.

## Галерея

Открой `index.html` — там все 9 иллюстраций с превью.

| # | Название | Описание |

| 01 | **Polynomial Nebula** | Корни полинома как звёзды туманности |
| 02 | **Coefficient Symphony** | 9 слайдеров = ландшафт из полиномов |

| 05 | **Polynomial Aurora** | Северное сияние из полиномиальных кривых |
| 06 | **Root Mixer** | Drag&drop корней — плотность, итерации, фаза |
| 07 | **Polynomial Mandala** | Симметричная мандала из корней |
| 08 | **Polynomial Symphony** | Частицы + шифрование в полиномах |
| 09 | **PolyCrypt** | Полиномиальный шифр уровня B |

## Математика

В основе каждой иллюстрации — полином:

$$P(z) = a_0 + a_1 z + a_2 z^2 + \dots + a_n z^n$$

Коэффициенты $a_i$ задают визуальную форму. Корни на комплексной плоскости — это точки, где $P(z) = 0$.

### Методы визуализации

- **Density Plot** — цвет зависит от количества итераций при вычислении фрактала
- **Root Finding** — Newton-Raphson для нахождения корней
- **Phase Plot** — цвет определяется углом суммарного поля корней
- **Iterative Field** — частицы движутся по градиенту суммарного поля корней

## PolyCrypt

Полиномиальный шифр уровня B (Confidential):

- Текст → коэффициенты полинома
- Ключ задаёт перестановку степеней
- Зашифрованное сообщение — корни полинома
- Дешифровка — восстановление текста из коэффициентов

## Использование

```bash
# Открыть галерею
open index.html

# Или каждую иллюстрацию отдельно
open 01-polynomial-nebula.html
```

Без зависимостей. Без сборки. Без сервера. Просто HTML.
